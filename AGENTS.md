# Agent Instructions

- Write the least code needed to solve the task correctly.
- Prefer clear, direct code over clever abstractions.
- Reuse existing functions, patterns, and dependencies before adding new ones.
- Avoid new files, helpers, comments, and configuration unless they reduce real complexity.
- Keep changes tightly scoped to the requested behavior.
- Remove dead code and duplication when it is directly related to the task.
- Add tests only where they protect meaningful behavior or prevent likely regressions.
