# Product

## Register

product

## Users

Branchboard is for personal use by one person exploring ideas, questions, and follow-up threads. The user is working in a thinking mode: reading, selecting useful answer fragments, and branching without losing the surrounding context.

## Product Purpose

Branchboard turns a linear chat into a spatial board. It helps the user keep related questions visible, return to earlier reasoning, and branch from specific answer text without flattening everything into one thread. Success means the workspace feels calm enough for long sessions and clear enough that moving, reading, asking, and branching stay obvious.

## Brand Personality

Warm, focused, utilitarian. The interface should feel like a private working canvas, not a public demo or a marketing surface.

## Anti-references

Avoid flashy AI chat tropes, decorative gradients, glass effects, oversized hero typography, noisy dashboards, saturated inactive states, and novelty controls that slow down the thinking flow.

## Design Principles

1. Keep the canvas primary. Controls should be reachable, but they should not compete with the board.
2. Use warmth for orientation, not decoration. Amber marks action, focus, live readiness, and branch provenance.
3. Favor reading stamina. Message surfaces, line lengths, contrast, and spacing should support long personal sessions.
4. Preserve spatial context. Branches, edges, and node labels should clarify where ideas came from without adding visual noise.
5. Prefer familiar controls. Personal tools still benefit from predictable buttons, fields, focus states, and keyboard paths.

## Accessibility & Inclusion

No formal accessibility target. Preserve practical accessibility for personal use: keyboard navigation, visible focus states, readable contrast, semantic controls, and reduced-motion support.
